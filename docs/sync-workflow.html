OmSree CRM ⇄ MS Access — How the Sync Agent works

A small application on the office PC keeps the MS Access database in step with the OmSree CRM. The web app stays the single source of truth; the Access file never leaves the office.

Each run  What the agent does

  1. Read the rows that changed in the OmSree CRM (PostgreSQL) — only the fields you mapped.
  2. Compare them against the current MS Access data to see what would change.
  3. Dry-run: if enabled, it shows a preview and writes nothing.
  4. Back up the .accdb file before the first write of the run.
  5. Apply the changes inside a transaction — the web value always wins.
  6. Record the result; on any failure it emails the chosen recipients.

In your control  From the admin console

  • Connections — set the Access file + the CRM database, with a Test connection button for each.
  • Mappings — choose which tables and fields sync, picking columns from live dropdowns; turn any field on or off.
  • Schedule — run every few minutes (cron), or press Sync Now on demand.
  • Direction — switch web→Access (and the optional Access→web) on or off.
  • Email & Logs — failure alerts to your inbox; a full history of every run.
